Family Drive Sync

A private, single-user personal tool.

What this application is

Family Drive Sync is a small personal tool written and used by one individual (the developer). It runs on the developer's own computer or private server and copies files that the developer already has legitimate access to into the developer's own Google Drive, then reads them back to check that every copy is intact. It keeps a private log of what was copied so that nothing is copied twice.

Who can use it

Only the developer. The application is not offered to the public, is not a product or service, and no one else is invited to sign in. It does not have user accounts, a public interface, or any feature for other people.

Why it asks Google for Drive access

To upload files to, and verify files in, folders in the developer's own Google Drive. It asks for the Google Drive permission (https://www.googleapis.com/auth/drive) because some of those folders were created earlier by other tools, and a narrower permission cannot see them. It is designed never to delete files.

Google verification status

This application has not been verified by Google. It is a personal-use application with a single user, so Google shows an "unverified app" notice when the developer signs in. That notice is expected and is accepted by the developer for his own account only.

Your data

This website does not collect any data: no cookies, no analytics, no forms, no accounts. See the Privacy Policy for how the application itself handles Google data.
